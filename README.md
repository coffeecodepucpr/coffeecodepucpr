O Coffee & Code é um clube de estudantes, para estudantes, que querem aprender tecnologia **construindo coisas**. Não é uma matéria extra nem um curso tradicional: é uma trilha de desenvolvimento acompanhada, em que você recebe estrutura, material e direção para aprender no seu ritmo.

```text
estudar → testar → errar → pesquisar → construir → entender → compartilhar
```

Não precisa chegar sabendo programar. Perguntar é incentivado, e errar faz parte do processo.

## Como funciona

- 🌐 **100% online** — material, encontros e entregas acontecem pela internet.
- 📚 **14 semanas** de trilha, cada uma com um tema. O material de cada semana fica aqui no GitHub, em Markdown, para ler direto no navegador.
- 🛠️ **Projeto individual** — cada pessoa constrói o próprio projeto ao longo das semanas, do planejamento até o código.
- 🌱 ⚡ **Dois níveis no mesmo material** — explicações com calma para quem está começando e desafios extras para quem já programa.
- 🗓️ **Encontros semanais** para tirar dúvidas, programar junto e mostrar o que você fez:
  - quarta-feira, 20h00 às 21h30
  - sábado, 10h00 às 11h30

  Os dois trabalham o mesmo conteúdo. Escolha o que couber na sua semana.

## A trilha

| Semana | Tema | Material |
|---|---|---|
| 01 | Kickoff & Design System — Git, GitHub, Markdown, requisitos, UX/UI, Figma | [coffee-code-sem01](https://github.com/coffeecodepucpr/coffee-code-sem01) |

Novas semanas entram aqui conforme a trilha avança.

## Entregas da turma

Cada repositório de semana tem uma seção **"Entregas da turma"** com os projetos de quem já entregou, com links para o Figma e para as telas funcionando no navegador. Quer entregar o seu? O passo a passo está na pasta `entregas/` de cada semana.
